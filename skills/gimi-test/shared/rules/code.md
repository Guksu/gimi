# 코드 금지선 — `code/`

AI가 쓴 코드에서 흔히 나오는 슬롭이다. 리뷰(gimi-review)와 끝내기 전 검사(gimi-test)가 함께 쓴다. 규칙 하나가 `## {ID} {한 줄}` 절 하나다.

- `대상`은 프론트·백엔드·둘 다 중 하나다. `scripts/rules.mjs`가 설정 `.agents/gimi.json`의 `stacks`로 걸러 보인다.
- `검사`는 잡는 곳이다. error·warn은 끝내기 전 검사(`check.mjs`)가 바뀐 줄에서 찾는다. 리뷰는 gimi-review가 맥락(영향 범위·의도·이력)을 보고 판단한다.
- `근거`는 측정 결과다 — 기능 구현·테스트 작성 요청 12개를 gimi 없이·있이 2번씩 실행해 그 줄이 나온 실행 수("N번 중 M번"). SKILL.md 표에는 gimi 없이 한 번 이상 나온 줄만 올라간다. 측정 전인 줄과 셀 수 없던 줄은 그렇게 적는다.
- 일부러 남길 줄은 그 줄 끝이나 바로 윗줄에 `// gimi-ignore: {ID} — {이유}`를 단다. 이유가 없으면 무시하지 않는다.
- 백엔드 줄은 언어와 상관없이 쓴다. 언어별 코드 신호는 예로만 든다.
